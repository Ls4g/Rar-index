# RAR private alpha — tester brief

RAR is a research-first collectible database. This first alpha is for testing whether the information is useful and understandable; it is not investment advice and it does not yet cover every edition or sale.

## Please try these five things

1. Search or browse for a manga you recognise, then tell us whether you found the edition you expected.
2. Open an edition and use its source links. Was it clear what RAR knows, what is still under review, and what the evidence means?
3. Add one RAR edition to your portfolio. Did the flow feel obvious?
4. Use **Request an edition** for something missing. Include a publisher or marketplace source if you have one.
5. Tell us one question RAR did not answer but should answer for a collector.

## Please report

- Broken or confusing links
- Incorrect edition identity, language, publisher or printing information
- A real completed sale RAR should investigate (include the source link)
- Anything that makes the site feel untrustworthy or difficult to use

RAR reviews all requests before they affect the public catalogue or price evidence.
